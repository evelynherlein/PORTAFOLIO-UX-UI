## 1. Descripción del proyecto

Este proyecto consiste en el diseño y desarrollo de mi portafolio web personal, realizado como trabajo final de la materia Diseño UX/UI.

El objetivo es presentar mis habilidades, conocimientos, formación académica y proyectos desarrollados durante la carrera, mediante una interfaz moderna, intuitiva, accesible y adaptable a diferentes dispositivos.

El sitio utiliza una identidad visual propia basada en tonos violetas, una estructura organizada y componentes reutilizables.

El desarrollo busca aplicar los principios de experiencia de usuario (UX), diseño de interfaces (UI), accesibilidad, usabilidad y diseño responsive.

## 6. Proceso de diseño UX/UI

### Investigación

Se definió como público objetivo a personas interesadas en conocer mis habilidades, proyectos y formación académica.

Entre los posibles usuarios se encuentran reclutadores, docentes, profesionales y personas interesadas en el desarrollo web.

### Concepto visual

La identidad visual del portafolio se basa en tres conceptos:

**Creatividad, organización y tecnología.**

Se eligió una paleta de colores violetas y una estética moderna para transmitir creatividad, profesionalismo y claridad.

### Arquitectura de información

Se organizaron las secciones para facilitar el recorrido del usuario y permitir el acceso rápido a los proyectos, habilidades y medios de contacto.

### Wireframes

Se contemplaron distribuciones para computadora y dispositivos móviles, priorizando la jerarquía visual y la legibilidad.

### Design System

El sistema de diseño contempla:

- Paleta de colores.
- Tipografías.
- Espaciados.
- Botones.
- Tarjetas.
- Componentes de navegación.
- Campos de formulario.
- Estados interactivos.

### Prototipado

Se utilizó Figma para representar la interfaz y su navegación.

### Validación de usabilidad

Se plantearon tareas para evaluar la facilidad de navegación, la identificación de proyectos y el acceso a la información de contacto.

Los resultados de las pruebas deben documentarse una vez realizadas.

---

## 7. Diseño responsive

El portafolio está diseñado para adaptarse a diferentes tamaños de pantalla.

Se contemplan tres resoluciones principales:

- Celular: 375 px.
- Tablet: 768 px.
- Computadora: 1280 px o superior.

El objetivo es mantener una experiencia de navegación consistente y accesible.

---

## 8. Accesibilidad

Se tuvieron en cuenta criterios de accesibilidad como:

- Uso de HTML semántico.
- Textos alternativos en imágenes.
- Organización jerárquica de títulos.
- Contraste visual.
- Navegación mediante teclado.
- Adaptación a dispositivos móviles.
- Etiquetas descriptivas en formularios.

La conformidad con WCAG 2.2 AA debe verificarse mediante pruebas.

## 9. Instalación y ejecución

Para ejecutar el proyecto localmente:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Instalar la extensión Live Server si todavía no está instalada.
4. Abrir el archivo `index.html`.
5. Hacer clic derecho y seleccionar **Open with Live Server**.
6. El portafolio se abrirá en el navegador.

El proyecto utiliza HTML, CSS y JavaScript, por lo que no requiere instalar dependencias de Node.js para visualizar el sitio.
