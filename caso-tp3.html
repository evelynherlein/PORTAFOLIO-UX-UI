Trabajo práctico académico

HTML5CSS3GridFlexboxResponsive

Colección progresiva de 20 ejercicios de diseño y desarrollo web. El recorrido culmina en Mate&Co, una landing integradora de productos para mate.

01

Problema

Aplicar fundamentos de HTML y CSS de forma incremental, desde estructura semántica hasta patrones responsive y componentes más complejos.

02

Proceso y objetivo

Integrar Flexbox, Grid, variables CSS, media queries, animación, formularios, navegación fija y HTML semántico.

03

Solución

Veinte entregables independientes: estructura, formularios, layouts, mosaico, menú hamburguesa sin JavaScript, multi-step y landing final.

04

Resultado y aprendizajes

Resultado: 20 entregables y una landing integradora final.

  • HTML semántico
  • Grid y Flexbox
  • Variables y media queries
  • Formularios y estados nativos
